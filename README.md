# Catálogo de Produtos

Aplicativo desenvolvido em React Native com Expo para a atividade N1 de Desenvolvimento Mobile.

## Conceitos utilizados

- Objetos
- Array de objetos
- Arrow Functions
- Template Strings
- Desestruturação
- map
- filter
- find
- reduce
- Componentes
- Props
- Pressable e onPress

## Executar o projeto

npm install

npx expo start
